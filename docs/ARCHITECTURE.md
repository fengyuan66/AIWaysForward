# Architecture & maintenance guide

Vite + React 19 + React Router 7. No CSS framework, no UI kit, no icon library. Fonts self-hosted through Fontsource.

## Folder map


## Common tasks

**Edit copy.** Change the string in `src/content/*.js`. Then `npm run verify:content` (checks the *live Wix site* — only meaningful while the original is still up) and `npm run inventory` to refresh the doc.

**Add a news story.** Add an image to `source-assets/news/`, add a line to `jobs` in `scripts/optimize-media.mjs` (or reuse the `news/N.webp` loop), `npm run media`, then add an object to `news.items` in `src/content/news.js`. The first item is the lead story on `/innovation`; Home shows the first three.

**Update the featured speaker.** `src/content/career.js → speakers[0]`. Bio paragraphs are arrays of segments; a `{ href, text }` object becomes a link. Replace a "To Be Announced" entry by giving it `tba: false` fields (`talk`, `when`, `bio`, `join`, `note`) and extending `Career.jsx` to render more than one feature (today it renders `speakers[0]` as the feature and the rest as TBA slots).

**Add a page.** Create `src/pages/X.jsx` using `<PageHead title="…" />` + a `<section className="section section--flush-top">`, add a `<Route>` in `App.jsx`, and a link in `content/site.js → nav` if it belongs in the nav.

**Replace a TBD.** See `docs/TBD_REGISTER.md` — each row names the file and the change. Remove the corresponding `<Tbd />` when done.

**Re-run the image pipeline.** `npm run media` (idempotent; reads `source-assets/`, writes `public/media/`).

**Change a colour/font/space value.** `tokens.css` only. Component CSS must reference tokens (`var(--…)`); no raw hex or `font-family` names in `src/styles/`.

## Conventions

- Every colour/font/space/radius is a token. The design was built under a locked-token rule.
- Display type is roman (no italic headings). Playfair Display appears in two slots only (staff and speaker names).
- Clickable text never wraps (`white-space: nowrap` on buttons/links; the nav collapses at 1152px instead).
- Grid tracks that hold images use `minmax(0, 1fr)`; `html` and `body` use `overflow-x: clip`.
- The pill CTAs, nav and footer follow the handoff exactly; page-level layout varies by page on purpose (home: split studio, about/education/career: long document, services/news: index, FAQs: conversational).
- Stamp: the first lines of `src/styles/base.css` record genre, macrostructure, theme, nav/footer picks and a pre-emit critique line.

## Verified

- Content: 125 authored strings across 11 pages match the live site character-for-character (`npm run verify:content`).
- Layout: no horizontal scroll, no wrapped buttons/links on any route at 320, 375, 414, 768, 1100 and 1152px (scripted check).
- Build: `npm run build` produces a ~300 kB (≈ 95 kB gzip) JS bundle + 32 kB CSS; images lazy-load below the fold.
